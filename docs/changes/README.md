# Registro de mudancas

Este diretorio registra mudancas relevantes de produto, arquitetura, design e governanca.

Para cada mudanca significativa, crie um arquivo com o padrao:

```text
YYYY-MM-DD-resumo-curto.md
```

Exemplo:

```text
2026-08-23-initial-project-governance.md
```

## Estrutura sugerida

Cada registro deve conter:

- data;
- objetivo;
- arquivos alterados;
- resumo;
- decisoes;
- impacto;
- pendencias.

Mudancas menores podem aparecer apenas em `changelog.md`, desde que nao alterem arquitetura, produto, design ou processo.
