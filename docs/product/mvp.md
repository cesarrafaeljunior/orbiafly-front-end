# Escopo do MVP

Este documento descreve o escopo previsto para o MVP futuro. Nenhuma funcionalidade listada aqui esta implementada nesta etapa inicial de governanca.

## MVP inicial

Previsto futuramente:

- contas financeiras;
- categorias;
- receitas;
- despesas;
- transferencias;
- dashboard financeiro;
- visao mensal.

O MVP deve permitir que o usuario acompanhe entradas, saidas, movimentacoes entre contas, saldo atual e resumo mensal de forma simples.

## Fora do MVP inicial

Por enquanto, ficam fora do MVP inicial:

- Open Finance;
- importacao automatica bancaria;
- investimentos;
- cartoes de credito completos;
- parcelamento;
- assinatura compartilhada ou familiar;
- IA financeira;
- automacoes financeiras;
- marketplace;
- planos pagos;
- microservicos.

Esta lista nao e definitiva. Ela representa apenas o ponto de partida atual e deve ser revisada conforme o produto amadurecer.

## Decisoes pendentes

- Nivel de detalhamento do dashboard inicial.
- Regras de saldo inicial por conta.
- Modelo exato para recorrencias e parcelamentos.
- Tratamento de multiplas moedas.
- Criterios para suporte multiusuario.
