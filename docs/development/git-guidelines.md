# Diretrizes de Git

- Nao faca commits automaticamente sem pedido explicito.
- Nao altere remotos sem pedido explicito.
- Nao faca push sem pedido explicito.
- Nao crie branches sem pedido explicito.
- Mantenha mudancas pequenas e relacionadas ao escopo da tarefa.
- Nao misture refactors amplos com implementacoes de feature.
- Preserve alteracoes existentes feitas por outras pessoas ou agentes.
- Use mensagens de commit objetivas quando commits forem solicitados.

## Mudancas relevantes

Mudancas arquiteturais, visuais ou de escopo devem atualizar a documentacao apropriada e registrar entrada em `docs/changes/`.
