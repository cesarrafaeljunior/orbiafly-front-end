# Regras locais para `docs/`

Este diretorio contem a memoria de produto, arquitetura, design, desenvolvimento e mudancas do Orbiafly.

- Escreva sempre em portugues brasileiro.
- Seja objetivo e evite texto corporativo generico.
- Diferencie regra atual, decisao planejada e possibilidade futura.
- Marque pendencias explicitamente quando uma regra ainda nao estiver definida.
- Atualize links internos ao mover ou renomear documentos.
- Registre mudancas relevantes em `docs/changes/`.
- Registre decisoes tecnicas relevantes em `docs/architecture/technical-decisions.md`.
- Nao crie documentos vazios ou burocracia sem uso claro.
